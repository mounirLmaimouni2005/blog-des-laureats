# Blog des Lauréats de l'EFP

## 1. Présentation du projet

**Blog des Lauréats de l'EFP** est une application web qui permet aux lauréats de l'EFP de partager leurs expériences professionnelles à travers des articles. Elle offre également aux apprenants la possibilité de consulter ces témoignages afin de découvrir les parcours, les conseils et les expériences des anciens lauréats.

Le projet vise à créer une plateforme collaborative qui valorise les expériences des lauréats et facilite le partage des connaissances au sein de la communauté de l'EFP.

## 3. Objectifs du Sprint 0

Le Sprint 0 a pour objectif de préparer l'environnement de travail et de mettre en place les bases nécessaires à la réalisation du projet.

Les principaux objectifs sont :

- Initialiser le dépôt Git et configurer le dépôt distant GitHub.
- Mettre en place la structure officielle du projet.
- Créer et documenter le fichier `.gitignore`.
- Préparer le fichier `README.md`.
- Organiser les dossiers de documentation, de développement et de gestion Scrum.
- Définir l'organisation de l'équipe et les rôles Scrum.
